 Introduction

## What is Kotlin?

Kotlin is a modern programming language developed by JetBrains.

Google officially supports Kotlin for Android development.

Kotlin is fully compatible with Java.

## Keywords

fun -> Used to create a function.

main() -> Entry point of every Kotlin program.

println() -> Used to print output on the console.

## Example

fun main() {
println("Hello, Kotlin!")
}

# Output

Hello, Kotlin!
