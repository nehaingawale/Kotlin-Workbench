Variables, Data Types, Operators and User Input

## Variables

Variables are used to store data.

# var
- Mutable (value can be changed)

Example:
var name = "Neha"
name = "Rahul"

# val
- Immutable (value cannot be changed)

Example:
val country = "India"


## Data Types

Data Type  Example

 Int -> 25
 Double -> 95.5
 Float -> 10.5f
 Long -> 123456789L
 Boolean -> true
 Char -> 'A'
 String -> "Neha"



## Operators

# Arithmetic Operators
`+  -  *  /  %`

# Comparison Operators
`==  !=  >  <  >=  <=`

# Logical Operators
`&&  ||  !`



# User Input

Use readln() to take input.

String Input:
val name = readln()


Integer Input:

val age = readln().toInt()


Double Input:
val marks = readln().toDouble()

- var -> Value can change.
- val -> Value cannot change.
- Data types define the type of data.
- Operators perform calculations and comparisons.
- readln() is used to take user input.
